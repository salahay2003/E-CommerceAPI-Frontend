# E-Commerce API Frontend

A simple Angular frontend application built to demonstrate and interact with the E-Commerce API backend.

This project showcases core e-commerce functionality such as authentication, product browsing, cart operations, and API integration using Angular.

> Note: This frontend is currently a work in progress and was primarily built to demonstrate the backend API functionality. Additional improvements and features will be added over time.

## Technologies Used

- Angular
- TypeScript
- HTML / Tailwind
- REST API Integration
- JWT Authentication

## Features

- User login
- Product display
- API integration with ASP.NET Core backend
- Basic frontend architecture using Angular

## Current Limitations

- Registration is not implemented yet
- JWT tokens are currently stored in local storage
- UI/UX is still being improved
- Some features are incomplete

## Backend API Repository

This frontend requires the backend API project to function.

Download the backend API from:

```bash
https://github.com/salahay2003/E-CommerceAPI
```

## Getting Started

### 1. Clone the Frontend Repository

```bash
git clone https://github.com/salahay2003/E-CommerceAPI-Frontend.git
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Angular Application

```bash
ng serve
```

Navigate to:

```bash
http://localhost:4200/
```

## Running the Backend API

1. Clone the backend repository
2. Configure the database connection string
3. Run database migrations
4. Start the ASP.NET Core API
5. Run the Angular frontend
